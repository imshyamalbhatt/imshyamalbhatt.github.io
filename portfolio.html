Pocket Money

Android app, also usable on the web · independent project

A personal finance app for tracking daily expenses and udhaar, the money you lend to or borrow from people. I designed it, built it with AI-assisted development, and keep improving it based on my own use and feedback from testers.

What it does

  • Expense tracking with categories, a minimal dashboard, and a full spending history
  • Udhaar tracking for money lent and borrowed, with reminders and one-tap WhatsApp nudges to the linked contact
  • Bill splitting, where each friend's share turns into an udhaar entry, plus a "Send to group" WhatsApp message
  • Trips and events: one-off spends are tagged automatically by date, kept out of the monthly budget, and shown in their own event view
  • Automatic spend detection from bank SMS, with a review list before anything is saved
  • Google Drive backup and optional Sign in with Google
  • Fingerprint or PIN app lock
  • Available in English, Hindi, Gujarati, and Marathi, with a light and dark theme
  • In-app update prompts, so new versions install straight from the app

How I built it

  • Wrote the product requirements and described each change in plain language, then built it with Claude as my development partner
  • Tested every change on a local phone preview before release, and shipped only after approving it
  • Packaged the web app as an installable Android app with native Android code for SMS reading, and publish releases through GitHub
  • Worked through real-world problems such as Android's Play Protect blocking sideloaded SMS apps, and adjusted the release process to fix them

SnipNote

Windows desktop app · independent project

A desktop utility that turns any text on screen into editable notes. I took it from an idea to a packaged Windows app using AI-assisted development, without a formal coding background.

What it does

  • Press a hotkey and select any area of the screen
  • Text inside the selection is read with OCR and saved as editable text
  • Captured text goes straight into an organized notes file, so nothing has to be retyped from screenshots
  • Scroll capture for pages longer than one screen
  • An optional review step to check text before it is saved

How I built it

  • Iterated through several releases based on real usage, improving capture accuracy each time
  • Packaged it as a standalone Windows build and shared it with others to test
  • Documented the build process publicly on LinkedIn
